# iOS – Hauckis möglicherweise nützliche App-Sammlung

Native SwiftUI/WKWebView-Hülle für dieselbe lokale App unter `../Shared/www/`.

- Bundle-ID: `de.matthiashauck.appsammlung`
- Deployment Target: iOS 15+
- Aktuelle Version: 1.0.1 / Build 2
- Kamera- und Fotobibliothekzugriff nur für den Zauberwürfel-Löser
- Externe Webnavigation im WKWebView gesperrt

Für Build, Signierung, TestFlight und App Store siehe `../Deployment/iOS/` und
`../Deployment/DEPLOYMENT_PLAN.md`.
